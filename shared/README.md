# Shared lab shell (planned)

Components every sim reuses, so each new sim is mostly science content:

- Info cards and the cross-lab Journal
- Fixed question box (typed or drawn answers)
- Drawing pad
- Pop-up calculator and formula-triangle helper
- Glossary terms and fun facts
- Onboarding tour
- Progress, badges and auto-save (localStorage with try/catch)
- My Worksheet export (PDF)

Force HQ has the most complete versions of these, so it is the starting point. Nothing has been extracted yet.

Already written: `table-graph-maker.js`, the journal table maker and the drag-to-plot graph maker first built for Tilt Lab (a reference copy to paste into the next sim's script; the header lists what it expects from the host).
